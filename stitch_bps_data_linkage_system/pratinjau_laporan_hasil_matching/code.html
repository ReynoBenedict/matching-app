Ringkasan Eksekutif

Proses pencocokan data antara basis data Sensus Penduduk BPS dengan Data Registrasi Administrasi Kependudukan Pemerintah Daerah telah selesai dilaksanakan. Proses ini bertujuan untuk mengidentifikasi tingkat kesesuaian data penduduk di wilayah Kota Malang guna mendukung kebijakan berbasis data yang presisi. Secara keseluruhan, tingkat pencocokan berhasil mencapai 87.4%, yang menunjukkan tingkat integritas data yang cukup baik antar instansi. Langkah verifikasi manual lanjutan direkomendasikan untuk 12.6% data anomali yang belum terselesaikan secara algoritmik.
