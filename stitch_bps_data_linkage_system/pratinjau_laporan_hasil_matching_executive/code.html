Ringkasan Eksekutif

Laporan ini menyajikan hasil pencocokan data komprehensif antara basis data Kependudukan (Dukcapil) dan basis data Kesejahteraan Sosial (DTKS) untuk wilayah Kota Malang periode Q3 2024. Proses pencocokan menggunakan algoritma hybrid (Exact Match dan Fuzzy Logic) untuk memastikan tingkat akurasi yang tinggi.

Tujuan utama dari proses ini adalah untuk mengidentifikasi anomali data, menghapus duplikasi, dan mempersiapkan dataset tunggal yang tervalidasi untuk program bantuan sosial mendatang. Hasil awal menunjukkan tingkat kesesuaian sebesar 84.5%, dengan sisa data memerlukan verifikasi manual lebih lanjut oleh tim lapangan.
